# Usage
 
## File Selection and Navigation
The annotator can navigate through the train and val folder images using both the ```arrow keys``` and the file explorer sections. In the file explorer sections the annotator can ```left click``` on the choice of image file to open it on the canvas, the annotation file of the same is automatically loaded (if it exists then the file name will be shown in green color, else in red color) and the overlay is provided on the image in the canvas. The annotator can also choose to navigate between the image files by pressing the ```right-arrow-key``` or the ```left-arrow-key```, moving swiftly between image files.
 
## Editing Existing Annotations
After the annotator has already opened the image file they wish to edit, they must click on the bbox or entity whose annotations they wish to edit on the canvas by ```left-click``` of the mouse. The respective annotation value opens on the JSON display and the annotator now has the options to edit the annotations by directly dragging the points or bbox corners to edit it or changing the values through the JSON file. The border of the canvas and the file name currently being edited will start to appear in the color yellow which means editing/changes are under progress. After making the annotations, the software checks it for proper validity, which is basically checking if the keypoints and/or the segmentation mask points lie within the bounding box. If the validation fails the annotator is displayed an error message, warning the annotator that one or more entities do not have properly oriented annotations. After the message is closed all such entities are marked out by red bounding boxes and the annotator can fix the annotations. The annotator saves the edited annotations with the keybindings ```Ctrl+s```  which saves the annotations on the respective label file on the disk. When reloaded the label file with the annotation is used for the overlay. The annotator can also delete particular points (they can be segmentation mask outline points or body keypoints) using the ```Delete``` key and undo their operations with ```Ctrl+z``` keybinding.
 
## Drawing Annotations from Scratch Manually
When the annotator wishes to draw annotations from scratch manually they can choose to draw, bounding box or keypoints or segmentation outline points. However they can only draw one modality at a given time, but can easily toggle the drawing mode using the keybindings for them. Please follow the following steps for each modality:
 
1. Drawing the bounding box: The annotator must ```left-click``` on the canvas, then press the ```b``` key on their keyboard, this activates the drawing fucntionality in bbox mode, allowing the annotator to hold and drag to draw a bounding box accross their image.
 
2. Drawing the keypoints: The annotator must ```left-click``` on the bounding box of the entity for whom they wish to draw keypoints, then press the ```k``` key on the keyboard. During the creation of the new dataset, or opening a dataset without labels the annotator is enquired about the list of keypoints they wish to keep for the dataset. The data.yaml generated from this is used to provide the annotator a sequence in which they can draw keypoints. For eg if the annotator has chosen to draw the nose, left_eye and right_eye keypoints then when they activate the keypoint drawing tool, they will automatically be allowed to first draw the nose keypoint, followed by the left_eye and the right_eye. Now it might be the case that for some entities a few kpts may not be visible correctly, for those keypoints the annotator can ```right-click``` on their mouse to skip that specific keypoint. If they re-draw a keypoint while it already exists the latest overwrites the old annotation, however it is undoable with ```Ctrl+z``` keybinding. After drawing the last keypoint the current drawable keypoint circles back to being the first keypoint, i.e. in the previous example, after drawing the nose, left_eye and right_eye, the annotaor will be again be able to re-draw the nose. The place the annotation keypoint the annotator simply hovers over to the correct location and does ```left-click``` on their mouse to draw that keypoint, after which they current keypoint to be drawn switches to the next keypoint. The skeleton for the entity joining the keypoints is drawn by the software itself, adapting to the available keypoints.
 
3. Drawing the segmentation mask outline: The annotator must ```left-click``` on the bounding box of the entity for whom they wish to draw the segmentation mask outline, then press the ```s``` key on the keyboard. The annotator can then start drawing the segmentation outline my tracing the outline of the entity, ```left-click``` on the mouse as they go to draw the next point to change trajectory of the mask outline. The annotator can do the ```double-left-click``` on their mouse to end drawing and the last segmentation outline point is automatically joined with the first to complete the mask.
 
4. Escaping from the drawing mode: The annotator can simply press the ```Esc``` key to escape from the drawing mode by exiting the tool.
 
## Auto Annotation for Single Image
The annotator can also choose to auto annotate a single image, by using the keybinding ```Ctrl+Shift+a``` on their keyboard, this activates the auto annotator, which then asks the annotator about the modalities they wish to annotate. The yolo11n-segpose model (or Prof Annotate) will then auto annotate the image and display the diff overlay on the canvas. The annotator can then either accept the auto-annotated output by pressing the ```Enter``` key or reject it by pressing the ```Esc``` key respectively. If they accept the auto annotated output, it simply overwrites the label file and pressing ```Ctrl+s``` saves it.
